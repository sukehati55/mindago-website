Build one page from model to practice

  1. Type a familiar name in Minda Teaching Plain and place it at the top of your page.
  2. Duplicate the name below and change that copy to Minda Dots.
  3. Leave a clear writing area for copying or an independent attempt.
  4. Print a test page and check size, spacing and dot visibility before making more copies.

This pair is useful when you create both teaching examples and tracing activities. If you only need one of those formats, either font is also available individually.

Character coverage

Both fonts include uppercase A–Z, lowercase a–z, numbers 0–9 and space. Minda Teaching Plain additionally includes !. Accented letters and other punctuation are not part of this verified character set; check a name before planning a worksheet.
