How to Make Name Tracing Worksheets for Preschool

A practical way to make a clear model, a tracing example and room for a learner to try their own writing.

If a learner is still working on basic line and pencil-control movements, start with our guide to pre-writing strokes for preschoolers before moving into personalised name tracing.

A child's name is a familiar starting point for a personalised early-writing activity. A simple worksheet lets you place the name, a dotted example and writing space together. You can adapt the page to the learner rather than fill every available line. It is a practice format to use with adult support, not a promise of a particular learning outcome.

Start with a blank document, the correctly spelled name and an application that supports your chosen fonts. A page with only a few well-spaced examples is enough for a first draft. The steps below use Amira as an example; replace it with a supported name of your choice.

1. Start with a simple name model

Type the name once, using the capitalisation you want the learner to see. Confirm its spelling with the family before making a class set. Make this first example large and clear, with plenty of white space around it. Keep it close to the practice area so it remains easy to refer to.

A clean handwriting model such as Minda Teaching Plain is one option. After installing the font on your computer, select it in an application that supports installed fonts. Word, PowerPoint and similar desktop tools can provide a place to arrange text and writing lines; available controls depend on your application and version.

2. Create the tracing version

Duplicate the name underneath the model and switch that copy to Minda Dots. Keep the spelling and capitalisation identical. Start with matching text sizes, then look at both examples together to check their visual size and spacing. Do not stretch the letters to make them fill a box.

These examples are live text using the actual fonts. On your worksheet, leave the dots dark enough to see clearly when printed. The font does not supply stroke-order arrows or instructions: demonstrate where to begin and how to move if the learner needs that guidance.

3. Give the learner enough writing space

Choose the letter size by looking at the printed page and the space available for a pencil, not just the screen preview. Begin with a generous example and enough height between rows to avoid one attempt running into another. There is no single font size that suits every name, page or learner.

For a long name, use a wider writing area or a landscape page before shrinking the letters substantially. Avoid squeezing the whole activity into a small corner. Keep margins clear of the printer's unprintable edges, and leave room for the learner's hand beside the writing area.

4. Offer a trace → copy → write progression

One possible layout is a tracing row, a copying row with the model still visible, and a final space for an independent attempt. This is an option, not the only correct teaching method. You can stay with the tracing row, demonstrate again or shorten the activity according to the learner's needs.

Use short labels and explain the task aloud rather than expecting a preschooler to read the instructions independently. If three stages make the page too busy, begin with just a model and a single tracing example. Add another writing space on a later page.

5. Keep the worksheet visually calm

Give each area one job. Place the model first, the tracing example next and any empty writing lines below. Use clear spacing or a simple heading to separate them. Keep decorative pictures away from letter outlines and writing lines, where they could make the intended path harder to distinguish.

A small picture or a little colour can make the page welcoming, but the name should remain the main focus. Check that labels are easy to read in black and white too. Avoid adding several typefaces, patterned backgrounds or a full page of repeated names just to fill space.

6. Print one test page first

Before printing a stack, print one copy on the paper and printer you intend to use. Check that the dots remain separate and visible, the solid model is clear and the writing lines are not too faint. Inspect the smallest letters as well as the overall page.

  • Check the selected paper size and page orientation.
  • Review printer scaling: an unexpected fit-to-page setting can reduce your carefully chosen letter size.
  • Confirm that no name, label or writing line is cut off at the margins.
  • Try a pencil on the page to judge whether the writing space is comfortable.

If you export a PDF, open that file and inspect it before printing. Keep an editable master for your own revisions, and check the font license before sharing files with someone else.

7. Make versions for different names

Save your layout as a reusable master, then replace the name in both the model and tracing rows. Check each version individually: a short name and a long name may need different spacing. Keep each name on one line where practical, without distorting its letter shapes.

Both Minda fonts include A–Z, a–z, 0–9 and space; Minda Teaching Plain also includes !. Do not assume a name with an accent, apostrophe, hyphen or another special character is supported. Check the complete name first. If it needs an unsupported character, choose an appropriate alternative font for that activity rather than changing the child's spelling.

8. Use the Minda model-to-tracing workflow

Minda Teaching Plain supplies the clean model, and Minda Dots supplies the tracing version. Together they offer a straightforward way to prepare paired examples while you decide the teaching approach, page layout and amount of practice.

If you need both formats, the Minda Font Bundle includes both fonts. You can also browse the individual fonts in Teaching Resources. These are digital fonts for creating your own resources, rather than a ready-made name worksheet generator.

If your Canva plan or workspace supports custom font uploads, check its current upload instructions and your font license before using that workflow. Do not assume every account or app can accept a custom font. For shared or sold resources, review the included desktop license and separate-license uses; sharing a finished worksheet is different from redistributing the font file or an editable template.
