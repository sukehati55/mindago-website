# Nunito UI font

Self-hosted Nunito normal-style Latin variable WOFF2 from @fontsource-variable/nunito 5.2.7.
Source: https://cdn.jsdelivr.net/npm/@fontsource-variable/nunito@5.2.7/files/nunito-latin-wght-normal.woff2
Upstream: https://github.com/google/fonts/tree/main/ofl/nunito
License: SIL Open Font License 1.1; see OFL.txt.

One 39,128-byte file supplies all existing UI weights (400–900), including 400, 600, 700 and 800. No external font request is made by the website.
